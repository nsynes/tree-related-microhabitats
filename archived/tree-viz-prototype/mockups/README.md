# Tree Microhabitats App - Photo-Based Design Mockups

## Overview

These mockups demonstrate a photo-based interactive approach for the Tree-Related Microhabitats explorer app.

## Mockup Flow

1. **`mockup-home.html`** - Species Selection
   - Beautiful cards for each tree species
   - Brief descriptions and scientific names
   - Click to select species

2. **`mockup-tree-overview.html`** - Tree Zone Selection
   - Full tree photo with interactive overlay zones
   - Zones: Canopy, Upper Trunk, Lower Trunk, Root Zone
   - Hover to highlight, click to explore
   - Side panel lists all zones with descriptions

3. **`mockup-zone-detail.html`** - Microhabitat Identification
   - Close-up photo of selected zone
   - Interactive hotspots mark specific microhabitats
   - Side panel lists all available microhabitats
   - Click hotspot or list item to view details

4. **`mockup-microhabitat.html`** - Detailed Information
   - Photo gallery of the microhabitat feature
   - Comprehensive description and identification tips
   - Wildlife associations
   - Conservation value
   - Mark as present/absent functionality

## Key Features Demonstrated

✅ **Photo-Based Interface** - Real photos instead of 3D models  
✅ **Progressive Detail** - Zoom from tree → zone → microhabitat  
✅ **Interactive Hotspots** - Click to explore specific features  
✅ **Educational Content** - Rich information at each level  
✅ **Easy to Use** - Simple click navigation  
✅ **Visual Appeal** - Clean, modern design  
✅ **Fine Detail** - Perfect for identifying bark texture, crevices, etc.  

## How to View

1. Open `mockup-home.html` in a web browser
2. Navigate through the flow by clicking elements
3. Note: These are static mockups with placeholder photos
